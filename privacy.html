Note Bounce – Política de Privacidade

Última atualização: 16 de outubro de 2026 · Read in English

Resumo

O Note Bounce não coleta, não vende e não compartilha dados pessoais. Não tem cadastro, login, anúncios, rastreadores nem análise de uso. A única exceção é a ativação opcional da versão Pro, descrita abaixo.

O que fica no seu aparelho

  • Suas preferências (como o tema claro/escuro e a posição das opções) ficam somente no armazenamento do próprio aplicativo, no seu aparelho.
  • Os arquivos MIDI que você abre são lidos localmente. Eles não são enviados a nenhum servidor.
  • Os projetos que você salva na biblioteca do aplicativo e o rascunho automático ficam somente no armazenamento do próprio aplicativo.
  • Os arquivos que você exporta (partitura em PDF, projeto em JSON, áudio WAV e MIDI) são criados no aparelho e só saem dele se você escolher salvar ou compartilhar.
  • Ao desinstalar o aplicativo ou limpar seus dados, esses dados locais são apagados.

Conexão com a internet

O aplicativo baixa de servidores públicos (CDN) as gravações do piano (Salamander Grand Piano) e, conforme a versão, a biblioteca de áudio (Tone.js) e a fonte (Inter). Como em qualquer acesso à internet, esses servidores podem registrar o endereço IP e dados técnicos básicos do aparelho. O Note Bounce não envia nenhuma informação sua nesses pedidos. Servidores usados: jsDelivr, cdnjs (Cloudflare) e GitHub Pages.

Ativação da versão Pro (opcional)

Se você ativar a versão Pro, o aplicativo envia ao servidor de licenças do desenvolvedor (uma planilha protegida do Google) apenas: (1) o código de ativação que você digitou e (2) um identificador anônimo do aparelho, que é um resumo criptográfico (hash) derivado do ID do Android — o ID original não é enviado. Isso serve só para que o código valha para um único aparelho e para restaurar o Pro se você limpar os dados ou reinstalar o aplicativo. Nenhum nome, e-mail, localização ou outro dado é enviado. Quem nunca ativa o Pro não envia nada. O pagamento (PIX) é feito fora do aplicativo.

Permissões

O aplicativo usa apenas a permissão de acesso à internet (para baixar os sons). Não acessa contatos, localização, câmera, microfone ou fotos. Arquivos só são lidos quando você os escolhe no seletor do sistema.

Crianças

O aplicativo não coleta informações de ninguém, incluindo crianças.

  • Áudio: Tone.js, licença MIT.

Note Bounce – Privacy Policy

Last updated: October 16, 2026

Summary

Note Bounce does not collect, sell or share personal data. It has no sign-up, login, ads, trackers or analytics. The only exception is the optional Pro activation described below.

What stays on your device

  • Your preferences (such as light/dark theme and your layout choices) are stored only in the app's own storage on your device.
  • MIDI files you open are read locally and are never uploaded to any server.
  • Projects you save to the in-app library and the automatic draft stay only in the app's own storage.
  • Files you export (PDF score, JSON project, WAV audio and MIDI) are created on your device and only leave it if you choose to save or share them.
  • Uninstalling the app or clearing its data deletes this local data.

Internet access

The app downloads the piano recordings (Salamander Grand Piano) and, depending on the version, the audio library (Tone.js) and the font (Inter) from public CDN servers. As with any internet request, those servers may log your IP address and basic technical device data. Note Bounce does not send any of your information in these requests. Servers used: jsDelivr, cdnjs (Cloudflare) and GitHub Pages.

Pro activation (optional)

If you activate Pro, the app sends to the developer's license server (a private Google spreadsheet) only: (1) the activation code you typed and (2) an anonymous device identifier, a cryptographic hash derived from the Android ID — the original ID is not sent. This is used only so that a code works on a single device and to restore Pro if you clear data or reinstall the app. No name, e-mail, location or other data is sent. If you never activate Pro, nothing is sent. Payment (PIX) happens outside the app.

Permissions

The app only uses internet access (to download sounds). It does not access contacts, location, camera, microphone or photos. Files are only read when you pick them in the system file picker.

Children

The app does not collect information from anyone, including children.
